# TNetworkObj
Server created by newxans and hosted for Project Enhanced's "CoMZ Enhanced," a rebalacing mod for CoMZ that focuses on balancing weapon prices, enemies, and overall gameplay.
## Command Help
-s 1 = 4.3 and above Servers
-s 2 = 4.2 and below Servers
